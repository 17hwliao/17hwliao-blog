2026年5月26日

REST 与 RESTful API 核心概念

REST 是一种客户端与 Web 服务器交互的架构风格

核心是用 HTTP 协议的 4 个请求方法代表不同操作：

  • GET：获取资源
  • POST：新建资源
  • PUT：更新资源
  • DELETE：删除资源

遵循 REST 风格的 API 称为 RESTful API，是当前前后端分离架构中主流的交互方式。
