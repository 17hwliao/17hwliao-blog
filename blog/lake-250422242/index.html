  • switch 模式匹配( 变量实现变量操作 )

不需要变量承载值 可以直接使用_ 来进行判断即可

String result = switch (obj) {
    case String s -> {
        // 🔥 这里可以使用变量 s 访问字符串的方法！
        int length = s.length();
        String upper = s.toUpperCase();
        yield "字符串: '" + s + "'，长度: " + length + "，大写: " + upper;
    }
    case Integer i -> {
        // 🔥 这里可以使用变量 i 进行数学计算！
        int square = i * i;
        double root = Math.sqrt(i);
        yield "整数: " + i + "，平方: " + square + "，平方根: " + root;
    }
    default -> "其他类型";
};
