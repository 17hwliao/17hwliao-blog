行内样式

在标签内使用style属性，属性值是css属性键值对。

内部样式

定义<style>标签，在标签内部定义css样式。

外部样式

定义<link>标签，通过href属性引入外部css文件

对于上述3种引入方式，企业开发的使用情况如下：

  • **行内样式：**会出现大量的代码冗余，不方便后期的维护，所以不常用（常配合JS使用）。
  • 内部样式**：**通过定义css选择器，让样式作用于当前页面的指定的标签上。（可以写在页面任何位置，但通常约定写在head标签中）
  • **外部样式：**html和css实现了完全的分离，企业开发常用方式。

采用内部样式, 选定需要修改的标签类型, 该种标签全部样式都会被修改 , 想更精进的化, 设置别名直接选择特定的转化格式 即可;

盒子模型

  • 盒子：页面中所有的元素（标签），都可以看做是一个 盒子，由盒子将页面中的元素包含在一个矩形区域内，通过盒子的视角更方便的进行页面布局。
  • 盒子模型组成：内容区域（content）、内边距区域（padding）、边框区域（border）、外边距区域（margin）。
布局标签

  • 布局标签：实际开发网页中，会大量频繁的使用 div 和 span 这两个没有语义的布局标签。

  • 标签：<div>``<span>

  • 特点：

  • <div>标签：//一般使用的布局标签 ;

  • 一行只显示一个（独占一行）

  • 宽度默认是父元素的宽度，高度默认由内容撑开

  • 可以设置宽高（width、height）

  • <span>标签：

  • 一行可以显示多个

  • 宽度和高度默认由内容撑开

  • 不可以设置宽高（width、height）

直观解释:

1. 核心尺寸与内容 (width & height)

  • width: 200px; 和 height: 200px;
  • 作用： 设定这个盒子的宽度和高度。
  • 比喻： 就像是快递箱里装的那件物品本身的大小（或者箱子原本的尺寸，具体取决于下文提到的 box-sizing）。

2. 内边距 (padding)

  • padding: 20px;
  • 作用： 设置内容（文字、图片等）到边框之间的内部距离。
  • 比喻： 快递箱里的防震气泡膜。它包裹在物品周围，保护物品不贴着纸箱内壁。气泡膜越厚，纸箱内部显得越满，但它属于纸箱内部的一部分。
  • 细节： 它可以拆分成 padding-top (上)、padding-right (右)、padding-bottom (下)、padding-left (左)。

3. 边框 (border)

  • border: 10px solid red;
  • 作用： 设置盒子的边缘线条。
  • **比喻：**纸箱本身的纸板厚度。它有厚度（10px）、样式（实线 solid）、颜色（红色 red）。这是盒子最外围的实体边界。

4. 外边距 (margin)

  • margin: 30px;
  • 作用： 设置这个盒子与其他盒子（其他标签）之间的外部距离。
  • 比喻： 快递箱和旁边其他快递箱之间的安全距离。它不属于纸箱本身，只负责把当前盒子和周围的元素推开，决定了盒子在网页中的摆放位置。

5. 背景色 (background-color)

  • background-color: aquamarine;
  • 作用： 设置盒子的背景颜色（这里是海蓝宝石色）。
  • 注意区域： 背景色会填满内容区域和内边距 (padding) 区域，直到边框的内边缘为止。外边距 (margin) 是透明的，不会显示背景色。

6. 重点：盒子的计算规则 (box-sizing)

这是初学者最容易踩坑的地方，也是你代码中非常关键的一句：

  • box-sizing: border-box;
  • 作用： 改变浏览器计算盒子总宽高的规则。

如果你不写这句代码，浏览器默认采用 content-box，这时候你会发现盒子“变胖”了：

默认情况 (content-box)： 你设置的 width: 200px 仅仅是里面“物品”的大小。 实际纸箱占用的宽度 = 内容(200) + 左右防震膜(20+20) + 左右纸板厚度(10+10) = 260px。盒子被撑大了！

表单标签

那其实，上述的整个窗口是一个表单，而表单是一项一项的，这个我们称为表单项 或 表单元素。

  • 表单场景: 表单就是在网页中负责数据采集功能的，如：注册、登录的表单。

  • 表单标签: <form>

  • 表单属性:

  • action: 规定表单提交时，向何处发送表单数据，表单提交的URL。

  • method: 规定用于发送表单数据的方式，常见为： GET、POST。

  • GET：表单数据是拼接在url后面的， 如 /路径 ? name=Tom&age=12，url中能携带的表单数据大小是有限制的。

  • 1.不安全 : 敏感信息一眼就能看见;

  • 2.浏览器中get 携带的表单数据的大小有大小限制 ;

  • POST： 表单数据是在请求体（消息体）中携带的，大小没有限制。
    1.安全 ;

  • 2.携带的数据大小没有限制;

  • 表单项标签: 不同类型的input元素、下拉列表、文本域等。

  • input: 定义表单项，通过type属性控制输入形式

  • select: 定义下拉列表

  • textarea: 定义文本域
