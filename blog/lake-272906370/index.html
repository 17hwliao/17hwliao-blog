GORM：模型、CRUD 与软删除

2026年6月7日

表结构

在gorm中，使用结构体表示一张表

例如User表

通常情况下，我们会使用Model结尾表示它是表的结构体

Go复制代码

type UserModel struct {
  ID        int64     `gorm:"primaryKey"` // 主键
  Name      string    `gorm:"not null;unique"` // 不能为空，且唯一 
  CreatedAt time.Time // 在创建记录时自动设置为当前时间
}

标签参考这个 https://gorm.io/zh_CN/docs/models.html#字段标签

封装数据库连接 , 使用一个全局的变量使用 var .DB

使用gorm实现的数据库连接直接连接到 全局变量中去 ;

GORM 是一个功能强大的 ORM 库，提供了丰富的数据库操作方法。以下是 GORM 提供的主要方法分类：

一、创建数据 (Create)

方法

说明

Create(&model)

插入单条记录

CreateInBatches(models, batchSize)

批量插入

FirstOrCreate(&dest, conditions)

查找或创建

CreateWithOption(&model, option)

带选项的创建

二、查询数据 (Query)

方法

说明

First(&dest, conditions)

查询第一条记录

Last(&dest, conditions)

查询最后一条记录

Take(&dest)

获取任意一条记录

Find(&dest, conditions)

查询多条记录

FindInBatches(&dest, batchSize, fc)

分批查询

Pluck(column, &dest)

查询指定字段

Count(&count)

统计数量

Where(conditions)

添加 WHERE 条件

Order(column)

添加排序

Limit(n)

限制条数

Offset(n)

偏移量

三、更新数据 (Update)

方法

说明

Save(&model)

保存（含新增或更新）

Update(column, value)

更新单个字段

Updates(map[string]interface{})

更新多个字段

UpdateColumn(column, value)

直接更新（跳过钩子）

UpdateColumns(map[string]interface{})

批量直接更新

四、删除数据 (Delete)

方法

说明

Delete(&model, conditions)

软删除（需要 DeletedAt

字段）

Unscoped().Delete(&model)

五、关联操作 (Association)

方法

说明

Association(column)

获取关联

Append(models...)

添加关联

Replace(models...)

替换关联

Clear()

清除关联

Delete(models...)

删除关联

六、事务 (Transaction)

方法

说明

Begin()

开始事务

Commit()

提交事务

Rollback()

回滚事务

Transaction(fc)

自动事务（推荐）

七、数据库迁移 (Migration)

方法

说明

AutoMigrate(models...)

自动迁移表结构

CreateTable(models...)

创建表

DropTable(models...)

删除表

获取迁移器

八、原生 SQL

方法

说明

Raw(sql, args...)

执行原生 SQL 查询

Exec(sql, args...)

执行原生 SQL 命令

Scan(&dest)

将结果扫描到结构体

示例代码：

// 查询
var user UserModel
Global.DB.Where("name = ?", "ws").First(&user)

// 更新
Global.DB.Model(&user).Update("age", 20)

// 删除
Global.DB.Delete(&user)

// 事务
err := Global.DB.Transaction(func(tx *gorm.DB) error {
    if err := tx.Create(&UserModel{Name: "test"}).Error; err != nil {
        return err // 回滚
    }
    return nil // 提交
})

自动生成表(表的迁移)

Go复制代码

package main

import (
  "fmt"
  "gorm.io/driver/mysql"
  "gorm.io/gorm"
  "time"
)

type UserModel struct {
  ID        int64     `gorm:"primaryKey"`      // 主键
  Name      string    `gorm:"not null;unique"` // 不能为空，且唯一
  CreatedAt time.Time // 在创建记录时自动设置为当前时间。
}

func main() {
  // 连接数据库
  db, err := gorm.Open(mysql.Open("root:root@tcp(127.0.0.1:3306)/gorm_new_db?charset=utf8mb4&parseTime=True&loc=Local"), &gorm.Config{})
  if err != nil {
    fmt.Println(err)
    return
  }
  
  err = db.AutoMigrate(&UserModel{})
  if err != nil {
    fmt.Println(err)
    return
  }
  fmt.Println("生成表结构成功！")
}

生成表结构只会新增字段，不会删除字段和更新字段]

批量插入

Go复制代码

// InsertData 插入数据
func InsertData() {

特别注意：Create函数接收的参数是结构体的指针或者是切片

插入数据的钩子 . 这里使用的钩子函数的函数名需要实现固定, 是底层内部的接口实现的说 ;

Go复制代码

type UserModel struct {
  ID        int64     `gorm:"primaryKey"`      // 主键
  Name      string    `gorm:"not null;unique"` // 不能为空，且唯一
  CreatedAt time.Time // 在创建记录时自动设置为当前时间。
}

func (u *UserModel) BeforeCreate(tx *gorm.DB) error {
  fmt.Println("创建的钩子函数")
  u.Name = "枫枫"
  return nil
}

如果在插入的钩子函数中，返回错误，则数据不会被插入

查询数据

Go复制代码

// 查全部
var users []UserModel
DB.Find(&users)
fmt.Println(users)

// 带条件查询
users = []UserModel{}
DB.Find(&users, "name = ?", "张三")
fmt.Println(users)

// 获取一条记录
var user UserModel
DB.Take(&user)
fmt.Println(user)

// 如果查不到则会报错
user = UserModel{}
err := DB.Take(&user, "id = ?", 100).Error   //使用Take  First实现使用主键去查数据  
if err == gorm.ErrRecordNotFound {
  fmt.Println("不存在的记录")
}

// 如果不想出现错误
user = UserModel{}
err = DB.Limit(1).Find(&user, "id = ?", 100).Error
fmt.Println(err)

// 打印实际的sql
DB.Debug().Take(&user, "id = ?", 1)

更新

有很多方法，Save、Update、UpdateColumn、Updates

不同的方法有不同的区别，如下：

  1. Save，有主键记录就是更新，并且可以更新零值，否则就是创建
  2. Update，可以更新零值，必须要有条件
  3. UpdateColumn，可以更新零值，不会走更新的Hook
  4. Updates，如果是结构体，则更新非零值，map可以更新零值

save

Go复制代码

// 创建
var user = UserModel{
  Name: "枫枫1",
}
DB.Save(&user)
fmt.Println(user)

// 更新
user = UserModel{
  ID:        9,
  Name:      "枫枫2",
  CreatedAt: time.Now(),
}
DB.Save(&user)
fmt.Println(user)

更新钩子

Go复制代码

func (u *UserModel) BeforeUpdate(tx *gorm.DB) (err error) {
  fmt.Println("更新的钩子函数")
  return nil
}

Update和UpdateColumn

唯一区别就是会走一个 skiphooks --> true ;

Go复制代码

DB.Model(&UserModel{}).
  Where("id = ?", 1).
  Update("name", "张三")  // 走了更新钩子

DB.Model(&UserModel{}).
  Where("id = ?", 1).
  UpdateColumn("name", "张三")

Updates

Go复制代码

user 对象只是数据载体，.Models(&user) 告诉GORM：

1. 操作哪个表 - 根据结构体名推断表名

2. 更新哪条记录 - 结合Where条件确定

var user = UserModel{ID: 1}

DB.Model(&user).Updates(UserModel{
  Name: "张三丰",
})

user = UserModel{ID: 2}
// 不会更新零值
DB.Model(&user).Updates(UserModel{
  Name: "",
})

user = UserModel{ID: 2}
// 会更新零值
DB.Model(&user).Updates(map[string]any{
  "name": "",
})

Expr

通常用于获取原字段的数据

例如年龄加一

Go复制代码

DB.Model(&UserModel{}).
  Where("id = ?", 1).
  UpdateColumn("age", gorm.Expr("age + 1"))  //Expr获取原先的字段值 + 实现 ++操作

软删除

软删除 vs 直接删除：

特性 直接删除 软删除

数据状态 真正删除 标记删除

数据恢复 无法恢复 可以恢复

存储空间 释放空间 不释放空间

查询性能 更快 稍慢

如果你的模型包含了 gorm.DeletedAt字段（该字段也被包含在gorm.Model中），那么该模型将会自动获得软删除的能力

当调用Delete时，GORM并不会从数据库中删除该记录，而是将该记录的DeleteAt设置为当前时间，而后的一般查询方法将无法查找到此条记录。

查找被删除的记录

TypeScript复制代码

DB.Unscoped().Find(&users)

永久删除

TypeScript复制代码

db.Unscoped().Delete(&user)  // 真正删除数据
