  • 构造器

类都会自带一个无参数的构造方法

实际new Person()的时候就是调用构造方法创建对象

下面通过定义了构造无参数方法 ;

  1. 直接初始化 对象内部资源 ;
Person. class : 
Person(){
    name = "xiao_ming" ;
    age = 18 ;
    gender = "nan" ;
}
  1. 创建有参构造 : 实现在初始化的时候传入变量值
Person.class : 
Person(String name , int age , String gender){
    this.name = name ;
    this.age = age ;
    this.gender = gender ;
}

Person(String name , String gender){
    this(name , 16) ;
    this.gender = gender ;
    this.age = 187 ;
}

Person(String name , int age ){
    this.name = name ;
    this.age = age ;
}

上述代码中会发生初始化 age的覆盖 : 187 ;
