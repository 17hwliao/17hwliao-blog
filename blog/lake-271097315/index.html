Gin：文件响应与浏览器下载

2026年5月24日

用于浏览器直接请求这个接口唤起下载

Go复制代码

c.Header("Content-Type", "application/octet-stream")              // 表示是文件流，唤起浏览器下载，一般设置了这个，就要设置文件名
c.Header("Content-Disposition", "attachment; filename=3.文件下载.go") // 用来指定下载下来的文件名
c.File("3.文件下载.go")
  1. 要设置Content-Type，唤起浏览器下载
  2. 只能是get请求

r.GET("/file/*filepath", func(c *gin.Context) {
		fp := c.Param("filepath")
		fp = strings.TrimPrefix(fp, "/")
		// 防止路径穿越
		clean := filepath.Clean(fp)
		if strings.Contains(clean, "..") {
			c.JSON(http.StatusBadRequest, gin.H{"error": "invalid path"})
			return}
		info, err := os.Stat(clean)
		if err != nil {
			c.JSON(http.StatusNotFound, gin.H{"error": "file not found"})
			return
		}
		if info.IsDir() {
			c.JSON(http.StatusBadRequest, gin.H{"error": "not a file"})
			return
		}
		c.File(clean)
	})

方法解读 :

1. strings.TrimPrefix()

函数：strings.TrimPrefix(s, prefix string) string作用：删除字符串开头指定前缀

  • 本例：strings.TrimPrefix(fp, "/")

  • 场景：路由拿到的路径可能自带开头 /，统一删掉

  • 例子：

  • /a/b.txt → a/b.txt

  • file.txt → 不变用途：统一路径格式，避免前缀斜杠干扰路径判断

2. filepath.Clean()

函数：filepath.Clean(path string) string核心功能（路径标准化）

  1. 消除 . 当前目录、.. 上级目录
  2. 合并多余连续斜杠
  3. 去掉末尾多余 /
  4. 自动修正非法路径格式

示例

  • a/../b → b
  • ./upload//1.txt → upload/1.txt
  • ../../etc/passwd → ../../etc/passwd（不会自动删掉）

安全意义：把用户传入的杂乱路径转为系统标准路径，方便后续判断是否存在越界。

3. os.Stat()

函数：os.Stat(name string) (FileInfo, error)作用：获取文件 / 目录元信息，不打开文件 返回两个值：

  1. FileInfo：文件信息（大小、修改时间、是否文件夹）
  2. err：错误（文件不存在、权限不足等）

常用判断

  • err != nil → 文件不存在 → 返回 404
  • info.IsDir() → 是文件夹，拒绝访问

特点：轻量查询，只读属性，不读取文件内容。

标准库中的方法汇总 :

  • r.GET()：注册 GET 请求路由
  • c.Param()：获取路由占位符参数
  • c.JSON()：返回 JSON 格式响应
  • c.File()：直接响应本地文件
  • http.StatusXXX：HTTP 状态码常量
  • strings.TrimPrefix：剔除前缀字符串
  • filepath.Clean：路径清洗标准化
  • os.Stat：获取文件状态信息
  • info.IsDir()：判断是否为目录

Content-Type 命令表

HTTP 报文头部字段，用来告诉客户端 / 服务端：本次传输的数据是什么格式，浏览器 / 服务器会根据它解析内容。

取值

用途

text/html; charset=utf-8

返回 HTML 页面

application/json; charset=utf-8

返回 JSON 数据

text/plain; charset=utf-8

纯文本

application/octet-stream

二进制流，文件下载

multipart/form-data

表单 + 文件上传（客户端用）

image/jpeg

/ image/png

图片

Content-Disposition

属于 HTTP 响应头，作用：告诉浏览器收到内容后，是直接展示还是当成文件下载。

固定取值

用途

inline

内容在浏览器内直接打开

attachment; filename="xxx.xxx"

强制触发文件下载，指定默认文件名
