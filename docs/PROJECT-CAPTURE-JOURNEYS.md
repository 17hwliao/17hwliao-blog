## 真实操作与限制

- SQL 是实际 CLI 产物与归档 EXPLAIN 的回放，字段和判定没有改写。本地取图布局为长 JSON 和假设区域增加滚动视窗，避免阅读深处时裁掉标题与来源。这不代表重新实测了数据库性能。
- AgentMesh 使用实际 Go 网关、临时租户和真实 HTTP/SSE。各路由均连接显式测试适配器，不调用在线模型或真实账单。正常、失败与主动停止分别新建对话；停止场景断言本次首批数据已到达、最终完成片段未到达，避免用上一段历史误判取消成功。
- Zenix 使用完整已构建 App、实际 LocalLibrary / PersonalStore 与四首已提供的音频。歌单选择、播放、队列、暂停、聚焦及喜欢操作均在隔离环境执行；个人喜欢列表来自真实保存结果。保持静音，不读取日常播放器资料，不启动 Electron 窗口。
- TableCard 启动实际 Go 服务、创建临时 AI 房间、处理 WebSocket 和输入，并运行实际离线引擎。保存的 TUI 文本按 Unicode 单/双宽单元格渲染，避免中英文字体回退导致边框错列；房间和规则使用实际较小终端尺寸，减少不必要空白。没有手工重画棋盘或伪造网络状态。

本地博客仅加载静态图片，不需要上述取图后端持续运行。所有服务与目录均与日常资料隔离；临时网关已退出。

## 当前视觉模型核验

使用当前多模态视觉模型读取新增工作截图与最终页面、窄屏、弹层截图，按内容层级、可读性、对齐、遮挡、留白和操作一致性检查。没有用生成图片代替项目画面。

实际修正并重新读取的画面包括：

1. 长报告原文滚动时丢失标题上下文：改为证据区域内滚动，保留报告导航和来源。
2. 关闭播放队列后过早取图出现淡出叠影：等待实际队列节点退出后再截暂停画面。
3. 多个请求复用历史，主动停止画面可能混入前一条回复：分别新建对话，按本次流内容断言取图。
4. 终端字体回退破坏边框宽度：使用单元格宽度排版实际文本，重新取图核对边线。
5. 窄屏弹层增加原图入口后需要容纳标题：头部允许换行，并检查 320px 布局、链接更新与焦点恢复。

辅助步骤图与主视觉图全部保留，最终选图仍由用户决定。原文件没有封面时继续显示应用自己的默认封面，不补造专辑图片或性能数字。
