# 博客心情音乐

音频由用户提供，曲目和心情标签配置在 `src/config/music.json`：

| 标签 | 曲目 | 本地文件 |
| --- | --- | --- |
| emo | 唯一 | `only.mp3` |
| 疯狂 | loser | `loser.mp3` |
| 更加疯狂 | loser死冯版 | `loser-sifeng.mp3` |
| 欢快 | 二十二 | `twenty-two.mp3` |

页头音乐按钮展开选择面板，点击曲目标签立即播放，再次点击当前曲目暂停。切换曲目停止上一首。面板关闭或站内切页不会主动中断已选择的音乐；刷新页面恢复不播放状态。

默认不设置音频源，`preload='none'`，没有自动播放和自动切下一首。音频加载或播放失败会显示重试提示；快速切歌时只保留当前请求的状态。
